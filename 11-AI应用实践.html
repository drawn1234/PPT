AI 在协作中的四种角色

ROLE-BASED COLLABORATION
01
Solution Analyst

方案分析师

核心角色

将功能需求拆解为实现路径、系统边界与潜在风险， 由人工完成最终方案取舍。

输入需求 → 分析路径 → 输出方案
02
Code Reviewer

代码审查员

质量保障

检查实现逻辑、边界条件与潜在风险， 输出清晰、可执行的问题清单。

代码实现 → 风险审查 → 问题清单
03
Log Analyst

日志分析助手

问题排查

从日志和异常信息中提取有效证据， 收敛问题链路并定位根因方向。

提取日志 → 证据分析 → 根因线索
04
Knowledge Mentor

授课导师

能力提升

结合项目上下文讲解技术原理， 促进知识理解、实践迁移和经验沉淀。

知识问题 → 深度讲解 → 知识沉淀
CORE INSIGHT

AI 的价值不只是“回答问题”，而是通过 明确角色、 补充上下文和 设置验证环节， 参与完整研发协作。

从问答工具 → 协作角色
